# Hospital-Analytics-Dashboard

**Hospital Data Analysis Project | MySQL, SQL & Excel**

An interactive **Excel dashboard** developed to analyze patient data, hospital revenue, and key hospital performance metrics using SQL and Excel.

### 📊 Dashboard

![Hospital Analytics Dashboard](https://github.com/mandaneha/Hospital-Analytics-Dashboard/blob/main/Hospital-Dashboard.png)

### 📈 Key Insights

* Analyzed data from **1,000 patient records**.
* Analyzed patient information and hospital performance metrics using SQL.
* Examined **hospital revenue** and key business metrics.
* Created visualizations to present important trends and insights.

### 🔎 Dashboard Features

* Patient data analysis
* Revenue analysis
* Hospital performance analysis
* KPI summary
* Interactive Excel dashboard
* Charts and visualizations
* SQL-based data analysis

### 📋 Dataset

* **Records:** 1,000 patient records
* **Database:** MySQL
* **Analysis:** SQL & Excel

### 🛠️ Tools

* MySQL
* SQL
* Excel
* Data Analysis & Visualization

### ▶️ How to View

1. Download the Excel dashboard file.
2. Open it using **Microsoft Excel**.
3. Use the interactive filters and dashboard visualizations to explore the data.
